# Rejestr decyzji architektonicznych: Tailwind CSS

Decyzja: Użyć Tailwind CSS jako frameworka CSS do stylizacji interfejsu użytkownika.

## Czym jest Tailwind CSS?

Tailwind to framework CSS typu utility-first, który umożliwia szybkie tworzenie i dostosowywanie interfejsów użytkownika. Został zaprojektowany jako bardzo konfigurowalny i pozwala programistom pisać szczuplejszy i wydajniejszy CSS. Framework zapewnia zestaw predefiniowanych klas do bardzo szybkiej stylizacji UI.

## Kontekst

Budujemy aplikację internetową dla klienta, która wymaga responsywnego i konfigurowalnego interfejsu użytkownika. Klient oczekuje spójnej i nowoczesnej stylizacji. Zespół programistyczny ma doświadczenie w używaniu własnego CSS, ale chce poznać frameworki CSS, które mogą zaoszczędzić czas i wysiłek. Szukamy frameworka, który jest łatwy w użyciu, konfigurowalny i ma dużą społeczność wsparcia.

## Czynniki decyzji

- **Łatwość użycia:**  Chcemy frameworka, którego łatwo się nauczyć i który można zintegrować z naszym przepływem pracy.

- **Konfigurowalność:**  Chcemy frameworka, który można dostosować do wytycznych marki i motywu klienta.

- **Wsparcie dużej społeczności:**  Chcemy frameworka, który ma aktywną społeczność programistów i projektantów, mogącą zapewnić pomoc i zasoby w razie potrzeby.

- **Oszczędność czasu:**  Chcemy frameworka, który może zaoszczędzić czas i wysiłek przy stylizacji UI.

## Rozważane opcje

- **Bootstrap:**  Popularny framework CSS z wieloma gotowymi komponentami i dużą społecznością programistów.

- **Foundation:**  Inny popularny framework CSS, zaprojektowany z myślą o rozwoju mobile-first.

- **Materialize:**  Framework CSS oparty na języku projektowym Material Design Google z gotowymi komponentami do tworzenia UI.

- **Tailwind CSS:**  Framework CSS typu utility-first z naciskiem na konfigurowalność i wydajność.

## Wynik decyzji

Po rozważeniu opcji postanowiliśmy użyć Tailwind CSS z następujących powodów:

- **Łatwość użycia:**  Podejście Tailwind jest proste i łatwe do zrozumienia. Jego klasy narzędziowe przyspieszają budowanie UI.

- **Konfigurowalność:**  Tailwind pozwala na dostosowywanie, zapewniając zestaw plików konfiguracyjnych, które pozwalają programistom łatwo modyfikować domyślne style frameworka.

- **Wsparcie dużej społeczności:**  Tailwind ma bardzo aktywną społeczność programistów i projektantów, którzy stale tworzą nowe zasoby, wtyczki i narzędzia.

- **Oszczędność czasu:**  Tailwind może zaoszczędzić czas, pozwalając programistom skupić się na innych obszarach projektu.

Użyjemy klas narzędziowych Tailwind CSS do zbudowania UI naszego projektu. Zespół programistyczny będzie używał jego atomowego i modułowego systemu projektowego do pisania wydajnego i skalowalnego kodu CSS.
