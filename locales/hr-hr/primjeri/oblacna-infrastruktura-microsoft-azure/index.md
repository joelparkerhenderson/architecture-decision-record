# Zapis arhitekturne odluke: cloud infrastruktura Microsoft Azure" 

Naslov odluke: Usvajanje Microsoft Azurea kao cloud infrastrukture za našu organizaciju

Donositelj odluke: Glavni informacijski direktor

Datum: 2021-10-15

Status: Odobreno

## Pozadina

Organizacija planira migrirati s tradicionalne lokalne infrastrukture na cloud infrastrukturu. Kako bi to postigla, organizacija je vrednovala više pružatelja cloud usluga poput Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure i IBM Cloud. Svaki pružatelj ima vlastiti skup značajki, prednosti i strukturu cijena. Nakon detaljne analize zaključeno je da je Microsoft Azure najprikladnija opcija za našu organizaciju.

## Odluka

Usvojiti Microsoft Azure kao cloud infrastrukturu za našu organizaciju.

## Obrazloženje

Slijede razlozi za usvajanje Microsoft Azurea:

1. Sveobuhvatne usluge: Azure pruža cjelovit raspon cloud usluga od infrastrukture kao usluge (IaaS) do softvera kao usluge (SaaS) i platforme kao usluge (PaaS). To nam omogućuje korištenje usluga Azurea za rješavanje zahtjeva organizacije, poput pohrane, računanja, umrežavanja i analitike.

2. Skalabilnost i fleksibilnost: S Azureom možemo lako povećavati ili smanjivati resurse na temelju poslovnih zahtjeva. Azure također nudi fleksibilnost u odabiru operacijskog sustava, programskog jezika i okvira.

3. Sigurnost i usklađenost: Azure nudi visoku razinu sigurnosti i usklađenosti jer je usklađen s nekoliko industrijskih standarda poput ISO, SOC, HIPAA i PCI DSS. Azure također pruža napredne sigurnosne značajke poput mrežnih sigurnosnih grupa, vatrozida i zaštite od DDoS-a.

4. Hibridni cloud: Azure pruža besprijekorno hibridno cloud iskustvo, omogućujući organizacijama povezivanje lokalne infrastrukture s Azureom. To nam olakšava migraciju radnih opterećenja u cloud i daje nam fleksibilnost u odabiru mjesta pohrane podataka.

5. Isplativost: Azure nudi model cijena prema potrošnji, što znači da plaćamo samo korištene resurse. To nam pomaže uštedjeti troškove u usporedbi s tradicionalnom lokalnom infrastrukturom.

## Zaključak

Usvajanje Microsoft Azurea kao cloud infrastrukture za našu organizaciju u skladu je s našim poslovnim zahtjevima i nudi nekoliko koristi poput skalabilnosti, fleksibilnosti, sigurnosti i isplativosti. Stoga se preporučuje usvojiti Azure kao našu cloud infrastrukturu.
