# Запис на архитектурно решение: облачна инфраструктура Microsoft Azure" 

Заглавие на решението: Приемане на Microsoft Azure като облачна инфраструктура за нашата организация

Вземащ решението: Главен информационен директор

Дата: 2021-10-15

Състояние: Одобрено

## Контекст

Организацията планира да мигрира от традиционна инфраструктура на място към облачна инфраструктура. За да постигне това, организацията е оценила няколко доставчици на облачни услуги, като Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure и IBM Cloud. Всеки доставчик има свой набор от функции, предимства и ценова структура. След подробен анализ бе направен изводът, че Microsoft Azure е най-подходящият вариант за нашата организация.

## Решение

Да се приеме Microsoft Azure като облачна инфраструктура за нашата организация.

## Обосновка

Следват причините за приемането на Microsoft Azure:

1. Изчерпателни услуги: Azure предоставя пълна гама от облачни услуги — от инфраструктура като услуга (IaaS) до софтуер като услуга (SaaS) и платформа като услуга (PaaS). Това ни позволява да използваме услугите на Azure, за да отговорим на изискванията на организацията, като съхранение, изчисления, мрежи и анализи.

2. Мащабируемост и гъвкавост: С Azure можем лесно да увеличаваме или намаляваме ресурсите според бизнес изискванията си. Azure предлага и гъвкавост при избора на операционна система, език за програмиране и рамки.

3. Сигурност и съответствие: Azure предлага високо ниво на сигурност и съответствие, тъй като отговаря на няколко отраслови стандарта като ISO, SOC, HIPAA и PCI DSS. Azure предоставя и усъвършенствани функции за сигурност като групи за мрежова сигурност, защитни стени и защита от DDoS.

4. Хибриден облак: Azure предоставя безпроблемно хибридно облачно изживяване, което позволява на организациите да свържат своята инфраструктура на място с Azure. Това ни улеснява да мигрираме работни натоварвания към облака и ни дава гъвкавост да избираме къде да съхраняваме данните.

5. Рентабилност: Azure предлага ценови модел „плащане при употреба“, което означава, че плащаме само за използваните ресурси. Това ни помага да спестим разходи в сравнение с традиционната инфраструктура на място.

## Заключение

Приемането на Microsoft Azure като облачна инфраструктура за нашата организация съответства на бизнес изискванията ни и предлага няколко ползи като мащабируемост, гъвкавост, сигурност и рентабилност. Затова се препоръчва да приемем Azure като наша облачна инфраструктура.
