# Záznam architektonického rozhodnutí: Tailwind CSS

Rozhodnutí: Použít Tailwind CSS jako CSS framework pro stylování uživatelského rozhraní.

## Co je Tailwind CSS?

Tailwind je utility-first CSS framework, který umožňuje rychlý vývoj a přizpůsobení uživatelských rozhraní. Je navržen tak, aby byl vysoce přizpůsobitelný, a umožňuje vývojářům psát štíhlejší a efektivnější CSS. Tento framework poskytuje sadu předdefinovaných tříd pro velmi rychlé stylování UI.

## Kontext

Vytváříme webovou aplikaci pro klienta, která vyžaduje responzivní a přizpůsobitelné uživatelské rozhraní. Klient požádal o konzistentní a moderní stylování. Vývojový tým má zkušenosti s vlastním CSS, ale chce prozkoumat CSS frameworky, které mohou ušetřit čas a úsilí. Hledáme framework, který je snadno použitelný, přizpůsobitelný a má velkou komunitu pro podporu.

## Hnací síly rozhodnutí

- **Snadné použití:**  Chceme framework, který se snadno učí a lze ho integrovat do našeho vývojového pracovního postupu.

- **Přizpůsobitelnost:**  Chceme framework, který lze přizpůsobit pokynům značky a tématu klienta.

- **Podpora velké komunity:**  Chceme framework, který má aktivní komunitu vývojářů a designérů, kteří mohou v případě potřeby poskytnout pomoc a zdroje.

- **Úspora času:**  Chceme framework, který může ušetřit čas a úsilí při stylování UI.

## Zvažované možnosti

- **Bootstrap:**  Oblíbený CSS framework s množstvím předpřipravených komponent a velkou komunitou vývojářů.

- **Foundation:**  Další oblíbený CSS framework, který byl navržen pro vývoj s prioritou mobilních zařízení.

- **Materialize:**  CSS framework založený na jazyce Material Design od Googlu s předpřipravenými komponentami pro vývoj UI.

- **Tailwind CSS:**  Utility-first CSS framework se zaměřením na přizpůsobení a efektivitu.

## Výsledek rozhodnutí

Po zvážení možností jsme se rozhodli použít Tailwind CSS z následujících důvodů:

- **Snadné použití:**  Přístup Tailwindu je jednoduchý a snadno srozumitelný. Jeho utility třídy zrychlují tvorbu UI.

- **Přizpůsobitelnost:**  Tailwind umožňuje přizpůsobení poskytnutím sady konfiguračních souborů, které vývojářům umožňují snadno upravit výchozí styly frameworku.

- **Podpora velké komunity:**  Tailwind má velmi aktivní komunitu vývojářů a designérů, kteří neustále vytvářejí nové zdroje, zásuvné moduly a nástroje.

- **Úspora času:**  Tailwind může ušetřit čas, takže se vývojáři mohou soustředit na jiné oblasti projektu.

K sestavení UI našeho projektu použijeme utility třídy Tailwind CSS. Vývojový tým využije jeho atomický a modulární designový systém k psaní efektivního a škálovatelného kódu CSS.
