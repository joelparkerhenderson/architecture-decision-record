# Záznam architektonického rozhodnutí: programovací jazyk Python

## Kontext

Musíme se rozhodnout, zda pro náš projekt použijeme Python jako programovací jazyk. Náš projekt zahrnuje analýzu dat, strojové učení a webový vývoj.

## Rozhodnutí

Rozhodli jsme se použít Python jako primární programovací jazyk našeho projektu.

## Zdůvodnění

Python je všestranný programovací jazyk, který se široce používá v oblastech analýzy dat, strojového učení a webového
vývoje. Je to interpretovaný jazyk, což znamená, že se nemusí kompilovat, a má snadno čitelnou a srozumitelnou syntaxi. Mezi další důležité faktory našeho rozhodnutí patří následující:

1. **Dostupnost knihoven:** Python má obrovskou sbírku knihoven a frameworků, jako jsou NumPy, Pandas a Scikit-learn, což vývojářům usnadňuje implementaci algoritmů strojového učení a analýzu dat.

2. **Podpora komunity:** Python má velkou a aktivní komunitu vývojářů, kteří přispívají k jeho vývoji a poskytují podporu a vedení na různých fórech a webech. Začátečníkům to usnadňuje najít pomoc a naučit se jazyk.

3. **Škálovatelnost:** Python je škálovatelný, což znamená, že zvládne velké datové sady a složité aplikace. Lze ho také použít pro rychlé prototypování nebo vytváření malých aplikací s minimálním úsilím, takže nám usnadňuje začít projekt a rychle iterovat.

4. **Flexibilita:** Python lze použít pro různé typy projektů, včetně webového vývoje, vědeckých výpočtů, strojového učení atd. Je také kompatibilní s jinými programovacími jazyky, jako jsou Java a C++, což usnadňuje integraci s dalšími systémy.

## Důsledky

Používání Pythonu jako našeho programovacího jazyka má některé možné důsledky, například:

1. **Výkon:** Python může být při provádění určitých algoritmů pomalejší než kompilované jazyky jako C++, ale to lze zmírnit použitím optimalizovaných knihoven nebo napsáním kritického kódu v C++ a jeho propojením s Pythonem.

2. **Křivka učení:** Ačkoli má Python snadno naučitelnou syntaxi, může být náročné naučit se osvědčené postupy pro psaní efektivního a škálovatelného kódu. To lze překonat dodržováním konvencí, používáním frameworků a knihoven a vyhledáváním rad zkušených vývojářů.

3. **Kompatibilita verzí:** Různé verze Pythonu mohou mít odlišnou syntaxi a schopnosti, což může ztížit údržbu a aktualizaci projektů. Je důležité zvolit verzi Pythonu, která je široce podporovaná a kompatibilní s požadavky našeho projektu.
