# Architekturális döntési feljegyzés: Microsoft Azure felhőinfrastruktúra" 

A döntés címe: A Microsoft Azure bevezetése szervezetünk felhőinfrastruktúrájaként

Döntéshozó: Informatikai igazgató (CIO)

Dátum: 2021-10-15

Állapot: Jóváhagyott

## Háttér

A szervezet azt tervezi, hogy a hagyományos helyi (on-premises) infrastruktúráról felhőinfrastruktúrára költözik. Ennek eléréséhez a szervezet több felhőszolgáltatót értékelt, mint az Amazon Web Services (AWS), a Google Cloud Platform (GCP), a Microsoft Azure és az IBM Cloud. Mindegyik szolgáltatónak megvan a maga funkciókészlete, előnyei és árszerkezete. Részletes elemzés után arra jutottak, hogy a Microsoft Azure a legmegfelelőbb lehetőség szervezetünk számára.

## Döntés

A Microsoft Azure bevezetése szervezetünk felhőinfrastruktúrájaként.

## Indoklás

A Microsoft Azure bevezetésének okai:

1. Átfogó szolgáltatások: Az Azure a felhőszolgáltatások teljes körét nyújtja, az infrastruktúra mint szolgáltatástól (IaaS) a szoftver mint szolgáltatáson (SaaS) át a platform mint szolgáltatásig (PaaS). Ez lehetővé teszi, hogy az Azure-szolgáltatásokat kihasználjuk a szervezet követelményeinek megoldására, mint a tárolás, számítás, hálózat és elemzés.

2. Skálázhatóság és rugalmasság: Az Azure-ral könnyen skálázhatjuk az erőforrásokat felfelé vagy lefelé az üzleti igényeink szerint. Az Azure rugalmasságot is kínál az operációs rendszer, a programozási nyelv és a keretrendszerek megválasztásában.

3. Biztonság és megfelelőség: Az Azure magas szintű biztonságot és megfelelőséget kínál, mivel több iparági szabványnak megfelel, mint az ISO, SOC, HIPAA és PCI DSS. Az Azure fejlett biztonsági funkciókat is nyújt, mint a hálózati biztonsági csoportok, tűzfalak és DDoS-védelem.

4. Hibrid felhő: Az Azure zökkenőmentes hibridfelhő-élményt nyújt, lehetővé téve a szervezetek számára, hogy helyi infrastruktúrájukat összekapcsolják az Azure-ral. Ez megkönnyíti a munkaterhelések felhőbe költöztetését, és rugalmasságot ad az adatok tárolási helyének megválasztásához.

5. Költséghatékony: Az Azure használatalapú árazási modellt kínál, ami azt jelenti, hogy csak a felhasznált erőforrásokért fizetünk. Ez segít költségeket megtakarítani a hagyományos helyi infrastruktúrához képest.

## Összegzés

A Microsoft Azure bevezetése szervezetünk felhőinfrastruktúrájaként összhangban van üzleti követelményeinkkel, és számos előnyt kínál, mint a skálázhatóság, rugalmasság, biztonság és költséghatékonyság. Ezért javasolt az Azure bevezetése felhőinfrastruktúránkként.
