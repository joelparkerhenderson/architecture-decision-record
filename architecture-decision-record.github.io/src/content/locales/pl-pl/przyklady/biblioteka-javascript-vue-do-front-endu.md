## Decyzja

Postanowiliśmy przyjąć bibliotekę JavaScript Vue do front-endu na podstawie następujących czynników:

1. **Lekkość:**  Vue to lekka biblioteka, która oferuje funkcjonalność podobną do React i Angular, ale z mniejszym rozmiarem kodu.

2. **Łatwość nauki:**  Vue ma proste i intuicyjne API, które ułatwia naukę i użycie.

3. **Elastyczność:**  Vue to elastyczna biblioteka, która dobrze współpracuje z innymi bibliotekami lub frameworkami, zapewniając różne funkcjonalności.

4. **Wydajność:**  Vue zapewnia doskonałą wydajność dzięki szybkiemu renderowaniu i minimalnemu narzutowi.

5. **Silna społeczność:**  Vue ma rosnącą i silną społeczność, która oferuje wsparcie i zasoby użytkownikom.

3. Integracja z innymi bibliotekami lub frameworkami będzie łatwiejsza dzięki elastyczności Vue.

4. Aplikacja będzie miała lepszą wydajność i responsywność dzięki szybszemu renderowaniu i minimalnemu narzutowi.
