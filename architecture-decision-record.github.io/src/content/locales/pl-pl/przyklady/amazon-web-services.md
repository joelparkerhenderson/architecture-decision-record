# Rejestr decyzji architektonicznych dla Amazon Web Services

Tytuł: Przyjęcie Amazon Web Services jako infrastruktury chmurowej

## Decyzja

Po dokładnej ocenie różnych platform infrastruktury chmurowej postanowiono, że nasza organizacja przyjmie Amazon Web Services (AWS) na potrzeby swojej infrastruktury chmurowej.

## Tło

Nasza organizacja szybko się rozwija i potrzebujemy niezawodnej, skalowalnej infrastruktury chmurowej, aby sprostać wymaganiom naszego biznesu. Po rozważeniu wielu dostawców infrastruktury chmurowej stwierdzono, że AWS oferuje najbardziej odpowiedni zakres usług, który spełni nasze obecne i przyszłe wymagania.

## Rozważania

Na rynku jest wielu dostawców infrastruktury chmurowej, którzy okazali się niezawodni i wydajni. Jednak AWS nie tylko oferuje kompleksowy zestaw usług odpowiadający naszym potrzebom, ale ma także szeroką bazę klientów i historię udanych wdrożeń. AWS zapewnia również szeroki zakres zasobów wsparcia i szkoleniowych, aby nasz zespół mógł skutecznie pracować z platformą.

Ponadto AWS ma rozległą obecność globalną, z centrami danych w różnych regionach świata. Zapewnia to bezpieczeństwo naszych danych oraz wysoką dostępność naszych aplikacji i usług. AWS ma również solidne ramy bezpieczeństwa, które mają kluczowe znaczenie dla naszego biznesu.

Wreszcie AWS oferuje model płatności za rzeczywiste użycie, który daje nam elastyczność skalowania infrastruktury w zależności od zapotrzebowania. Oznacza to, że zapłacimy tylko za to, z czego korzystamy, co pozwala zoptymalizować koszty i inwestować w inne obszary biznesu.

## Decyzja

Na podstawie przeprowadzonych ocen i zalet oferowanych przez AWS postanowiono, że AWS zostanie przyjęty na potrzeby naszej infrastruktury chmurowej.

## Konsekwencje

Przyjęcie AWS może wymagać przeszkolenia naszych zespołów, aby znały platformę i potrafiły skutecznie z niej korzystać. Mogą też wystąpić początkowe koszty przeniesienia naszej obecnej infrastruktury na platformę AWS.

## Odpowiedzialność

Odpowiedzialność za skuteczne wykorzystanie AWS i zarządzanie związanym z tym ryzykiem spoczywa na zespole infrastruktury chmurowej. Wszelkie pojawiające się problemy musi rozwiązywać ten zespół.

## Przegląd

Decyzja o przyjęciu AWS będzie corocznie przeglądana, aby upewnić się, że nadal spełnia nasze potrzeby i że korzyści z platformy są w pełni wykorzystywane.
