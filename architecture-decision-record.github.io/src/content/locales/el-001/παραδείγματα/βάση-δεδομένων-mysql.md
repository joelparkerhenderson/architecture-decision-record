## Αποτέλεσμα της απόφασης

Μετά την αξιολόγηση των παραπάνω επιλογών βάσει των σκέψεών μας για την απόφαση, αποφασίσαμε να επιλέξουμε τη MySQL ως DBMS για το Έργο Χ.

Η MySQL είναι ένα δημοφιλές σύστημα ανοικτού κώδικα με ισχυρή κοινότητα ανάπτυξης και μεγάλο σύνολο πόρων για την επίλυση προβλημάτων και την ανταλλαγή γνώσεων. Είναι γνωστή για την εξαιρετική απόδοση και τις δυνατότητες κλιμάκωσής της, κάτι που την καθιστά ιδανική για τον χειρισμό τεράστιων ποσοτήτων δεδομένων με υψηλή αποδοτικότητα. Η πλατφόρμα είναι ασφαλής, αξιόπιστη και έχει ευρύ φάσμα χαρακτηριστικών απαραίτητων για το έργο μας, συμπεριλαμβανομένης της συμμόρφωσης ACID για συναλλαγές, ευέλικτου μοντέλου δεδομένων και υποστήριξης για διάφορες γλώσσες προγραμματισμού και πλαίσια.

Η MySQL είναι επίσης συμβατή με την πλειονότητα της στοίβας τεχνολογίας μας, συμπεριλαμβανομένου του πλαισίου ανάπτυξης ιστού, των λύσεων φιλοξενίας και άλλων απαραίτητων εργαλείων. Επιπλέον, το κόστος και οι όροι αδειοδότησής της είναι ανταγωνιστικοί σε σύγκριση με άλλα ιδιοκτησιακά συστήματα όπως η Oracle και ο Microsoft SQL Server.
