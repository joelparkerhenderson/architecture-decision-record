# Zapis arhitekturne odluke za Amazon Web Services

Naslov: Usvajanje Amazon Web Services za cloud infrastrukturu

## Odluka

Nakon temeljitog vrednovanja različitih platformi cloud infrastrukture odlučeno je da će naša organizacija usvojiti Amazon Web Services (AWS) za svoje potrebe cloud infrastrukture.

## Pozadina

Naša organizacija brzo raste i trebamo pouzdanu i skalabilnu cloud infrastrukturu kako bismo zadovoljili zahtjeve našeg poslovanja. Nakon razmatranja niza pružatelja cloud infrastrukture zaključeno je da AWS nudi najprikladniji raspon usluga za zadovoljenje naših trenutačnih i budućih zahtjeva.

## Razmatranja

Na tržištu postoje brojni pružatelji cloud infrastrukture koji su se pokazali pouzdanima i učinkovitima. Međutim, AWS ne nudi samo sveobuhvatan skup usluga koji zadovoljava naše potrebe, nego ima i golemu bazu korisnika i povijest uspješnih implementacija. AWS također pruža širok raspon resursa za podršku i obuku kako bi naš tim mogao učinkovito raditi s platformom.

Nadalje, AWS ima opsežnu globalnu prisutnost s podatkovnim centrima smještenima u različitim regijama diljem svijeta. To osigurava da su naši podaci sigurni te da će naše aplikacije i usluge biti vrlo dostupne. AWS također ima robustan sigurnosni okvir koji je ključan za naše poslovanje.

Konačno, AWS nudi model plaćanja prema potrošnji koji nam daje fleksibilnost skaliranja infrastrukture prema potražnji. To znači da ćemo plaćati samo ono što koristimo, što nam omogućuje optimizaciju troškova i ulaganje u druga područja poslovanja.

## Odluka

Na temelju provedenih vrednovanja i prednosti koje nudi AWS odlučeno je da će se AWS usvojiti za naše potrebe cloud infrastrukture.

## Posljedice

Usvajanje AWS-a može zahtijevati obuku naših timova kako bi se upoznali s platformom i mogli je učinkovito koristiti. Mogu postojati i određeni početni troškovi premještanja naše trenutačne infrastrukture na platformu AWS.

## Vlasništvo

Odgovornost za osiguravanje učinkovitog korištenja AWS-a i upravljanje povezanim rizicima pripast će timu za cloud infrastrukturu. Svako pitanje koje se pojavi mora riješiti taj tim.

## Pregled

Odluka o usvajanju AWS-a pregledavat će se jednom godišnje kako bi se osiguralo da i dalje zadovoljava naše potrebe te da se koristi platforme u potpunosti ostvaruju.
