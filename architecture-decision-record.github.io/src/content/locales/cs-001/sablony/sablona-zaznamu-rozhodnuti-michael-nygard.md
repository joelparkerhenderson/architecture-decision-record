# Šablona záznamu rozhodnutí od Michaela Nygarda

Toto je šablona z článku [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Ke správě souborů ADR můžete použít [adr-tools](https://github.com/npryce/adr-tools).

V každém souboru ADR napište tyto sekce:

# Název

## Stav

Jaký je stav, například navrhované, přijaté, zamítnuté, zastaralé, nahrazené atd.?

## Kontext

Jaký problém vidíme, který motivuje toto rozhodnutí nebo změnu?

## Rozhodnutí

Jakou změnu navrhujeme a/nebo provádíme?

## Důsledky

Co se kvůli této změně stane snazším nebo obtížnějším?
