# Záznam architektonického rozhodnutí pro Amazon Web Services

Název: Přijetí Amazon Web Services pro cloudovou infrastrukturu

## Rozhodnutí

Po důkladném vyhodnocení různých platforem cloudové infrastruktury bylo rozhodnuto, že naše organizace přijme Amazon Web Services (AWS) pro své potřeby cloudové infrastruktury.

## Pozadí

Naše organizace rychle roste a potřebujeme spolehlivou a škálovatelnou cloudovou infrastrukturu, která uspokojí požadavky našeho podnikání. Po zvážení řady poskytovatelů cloudové infrastruktury bylo dospěno k závěru, že AWS nabízí nejvhodnější rozsah služeb pro naše současné i budoucí požadavky.

## Úvahy

Na trhu existuje řada poskytovatelů cloudové infrastruktury, kteří se osvědčili jako spolehliví a efektivní. AWS však nejen nabízí komplexní sadu služeb, která uspokojí naše potřeby, ale má také rozsáhlou zákaznickou základnu a historii úspěšných nasazení. AWS také poskytuje širokou škálu zdrojů podpory a školení, aby náš tým mohl s platformou efektivně pracovat.

Kromě toho má AWS rozsáhlou globální přítomnost s datovými centry v různých regionech světa. To zajišťuje, že naše data jsou v bezpečí a naše aplikace a služby budou vysoce dostupné. AWS má také robustní bezpečnostní rámec, který je pro naše podnikání zásadní.

Konečně AWS poskytuje model platby podle skutečného využití, který nám dává flexibilitu škálovat naši infrastrukturu podle poptávky. To znamená, že budeme platit jen za to, co využijeme, což nám umožňuje optimalizovat náklady a investovat do jiných oblastí podnikání.

## Rozhodnutí

Na základě provedených hodnocení a výhod, které AWS nabízí, bylo rozhodnuto, že AWS bude přijato pro naše potřeby cloudové infrastruktury.

## Důsledky

Přijetí AWS může vyžadovat školení našich týmů, aby byly s platformou obeznámeny a mohly ji efektivně využívat. Mohou také vzniknout určité počáteční náklady na přesun naší stávající infrastruktury na platformu AWS.

## Vlastnictví

Odpovědnost za zajištění efektivního využití AWS a řízení souvisejících rizik spadá do pravomoci týmu cloudové infrastruktury. Veškeré vyvstalé problémy musí řešit tento tým.

## Revize

Rozhodnutí o přijetí AWS bude každoročně přezkoumáváno, aby se zajistilo, že nadále splňuje naše potřeby a že přínosy platformy jsou plně využity.
