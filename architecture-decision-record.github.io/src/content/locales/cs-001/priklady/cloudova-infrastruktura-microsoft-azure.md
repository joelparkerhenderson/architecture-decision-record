# Záznam architektonického rozhodnutí: cloudová infrastruktura Microsoft Azure" 

Název rozhodnutí: Přijetí Microsoft Azure jako cloudové infrastruktury pro naši organizaci

Rozhodovatel: Informační ředitel (CIO)

Datum: 2021-10-15

Stav: Schválené

## Pozadí

Organizace plánuje migraci z tradiční lokální (on-premises) infrastruktury na cloudovou infrastrukturu. K dosažení tohoto cíle organizace vyhodnotila několik poskytovatelů cloudových služeb, jako jsou Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure a IBM Cloud. Každý poskytovatel má svou vlastní sadu funkcí, výhod a cenovou strukturu. Po podrobné analýze bylo dospěno k závěru, že Microsoft Azure je pro naši organizaci nejvhodnější možností.

## Rozhodnutí

Přijmout Microsoft Azure jako cloudovou infrastrukturu pro naši organizaci.

## Odůvodnění

Důvody pro přijetí Microsoft Azure jsou následující:

1. Komplexní služby: Azure poskytuje úplný rozsah cloudových služeb, od infrastruktury jako služby (IaaS) přes software jako službu (SaaS) po platformu jako službu (PaaS). To nám umožňuje využít služby Azure k řešení požadavků organizace, jako je úložiště, výpočetní výkon, sítě a analýza.

2. Škálovatelnost a flexibilita: S Azure můžeme snadno škálovat zdroje nahoru nebo dolů podle našich obchodních požadavků. Azure také nabízí flexibilitu ve volbě operačního systému, programovacího jazyka a frameworků.

3. Bezpečnost a soulad: Azure nabízí vysokou úroveň bezpečnosti a souladu, protože je v souladu s několika průmyslovými standardy, jako jsou ISO, SOC, HIPAA a PCI DSS. Azure také poskytuje pokročilé bezpečnostní funkce, jako jsou skupiny zabezpečení sítě, firewally a ochrana před DDoS.

4. Hybridní cloud: Azure poskytuje bezproblémový zážitek z hybridního cloudu, který organizacím umožňuje propojit jejich lokální infrastrukturu s Azure. To nám usnadňuje migraci úloh do cloudu a dává nám flexibilitu zvolit, kam ukládat data.

5. Nákladově efektivní: Azure nabízí cenový model platby podle skutečného využití, což znamená, že platíme jen za využité zdroje. To nám pomáhá ušetřit náklady ve srovnání s tradiční lokální infrastrukturou.

## Závěr

Přijetí Microsoft Azure jako cloudové infrastruktury pro naši organizaci je v souladu s našimi obchodními požadavky a nabízí několik přínosů, jako je škálovatelnost, flexibilita, bezpečnost a nákladová efektivita. Proto se doporučuje přijmout Azure jako naši cloudovou infrastrukturu.
