Zvažovali jsme React, Vue a Angular, ale rozhodli jsme se proti nim z následujících důvodů:

1. **React:**  Ačkoli má React velkou uživatelskou základnu a spoustu knihoven a zdrojů, může být složitý a obtížně se učit, zejména pro začátečníky.

2. **Vue:**  Vue je lehká knihovna, která se snadno učí a používá, ale nemusí být tak rychlá ani optimalizovaná jako Svelte.

3. **Angular:**  Angular je komplexní framework, který nabízí mnoho funkcí a nástrojů, ale může být těžký a složitý a může vyžadovat více údržby než Svelte.
