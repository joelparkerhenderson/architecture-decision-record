# Záznam architektonického rozhodnutí: programovací jazyk Java

Název: Volba programovacího jazyka Java pro projekt

Rozhodnutí: Po vyhodnocení několika programovacích jazyků jsme se rozhodli pro náš projekt použít Javu.

### Pozadí

Zamýšleli jsme vytvořit webovou aplikaci, která by mohla běžet na více operačních systémech. Náš projekt vyžadoval jazyk, který by poskytoval silné bezpečnostní funkce, zvládal souběžnost, podporoval velké kódové základny a byl dostatečně univerzální, aby splnil naše budoucí požadavky na růst. Před volbou Javy jsme vyhodnotili několik jazyků s ohledem na jejich silné stránky a omezení.

### Úvahy

1. **Bezpečnost:**  Java poskytuje vynikající bezpečnostní funkce díky dobře definovaným bezpečnostním politikám a řízení přístupu. Zahrnuje také funkce, jako je ověřování bajtkódu, které pomáhá zabránit spuštění škodlivého softwaru v systému.

2. **Souběžnost:**  Java má vestavěnou podporu vícevláknovosti, která umožňuje aplikacím provádět několik úloh současně. Tato vlastnost činí z Javy výbornou volbu pro vývoj velkých, složitých aplikací s mnoha funkcemi a funkcionalitami.

3. **Velké kódové základny:**  Java podporuje objektově orientované programování, což z ní činí vhodnou volbu pro vývoj velkých kódových základen. Její modulární povaha a využití vzorů zapouzdření a abstrakce dále usnadňují proces vývoje softwaru.

4. **Univerzálnost:**  Java je univerzální a poskytuje možnost používat širokou škálu knihoven a frameworků, což z ní činí výbornou volbu pro webové i podnikové aplikace.

### Výsledek rozhodnutí

Rozhodli jsme se pro náš projekt použít programovací jazyk Java s ohledem na jeho bezpečnostní funkce, podporu souběžnosti, schopnost zvládat velké kódové základny a univerzálnost. Toto rozhodnutí je v souladu s požadavky našeho projektu a věříme, že volba Javy zajistí jeho úspěch.
