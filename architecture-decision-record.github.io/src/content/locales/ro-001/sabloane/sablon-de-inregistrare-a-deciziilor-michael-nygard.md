# Șablon de înregistrare a deciziilor de Michael Nygard

Acesta este șablonul din [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Poți folosi [adr-tools](https://github.com/npryce/adr-tools) pentru gestionarea fișierelor ADR.

În fiecare fișier ADR, scrie aceste secțiuni:

# Titlu

## Stare

Care este starea, de exemplu propusă, acceptată, respinsă, depășită, înlocuită etc.?

## Context

Care este problema pe care o vedem și care motivează această decizie sau schimbare?

## Decizie

Care este schimbarea pe care o propunem și/sau o facem?

## Consecințe

Ce devine mai ușor sau mai greu de făcut din cauza acestei schimbări?
