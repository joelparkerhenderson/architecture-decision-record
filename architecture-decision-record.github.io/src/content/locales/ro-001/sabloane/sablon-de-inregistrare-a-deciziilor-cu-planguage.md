# Șablon de înregistrare a deciziilor cu Planguage

Vezi https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Ce este Planguage?

Planguage este un limbaj de planificare care folosește aceste cuvinte-cheie:

* Tag: Un identificator unic și persistent
* Gist: Un rezumat scurt al cerinței sau al domeniului abordat
* Requirement: Textul care detaliază cerința propriu-zisă
* Rationale: Raționamentul care justifică cerința
* Priority: O declarație de prioritate și de pretenție asupra resurselor
* Stakeholders: Părțile afectate material de cerință
* Status: Starea cerinței (ciornă, analizată, asumată etc.)
* Owner: Persoana responsabilă de implementarea cerinței
* Author: Persoana care a scris cerința
* Revision: Un număr de versiune pentru enunț
* Date: Data celei mai recente revizuiri
* Assumptions: Orice ar putea cauza probleme dacă nu este adevărat acum sau mai târziu
* Risks: Orice ar putea cauza defecțiuni, întârzieri sau alte efecte negative
* Defined: Definiția unui termen (mai bine se folosește un glosar)
