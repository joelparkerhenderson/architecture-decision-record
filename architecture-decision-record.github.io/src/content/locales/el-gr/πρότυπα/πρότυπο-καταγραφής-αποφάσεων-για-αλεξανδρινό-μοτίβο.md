# Πρότυπο καταγραφής αποφάσεων για αλεξανδρινό μοτίβο

## Εισαγωγή

* Πρόλογος (Περίληψη)
* Συζήτηση (Πλαίσιο)
* Λύση (Απόφαση)
* Συνέπειες (Αποτελέσματα)

## Λεπτομέρειες ##

* Πρόλογος (Περίληψη)
  * Δήλωση για περίληψη:
    * Στο πλαίσιο του (περίπτωση χρήσης)<br>
      αντιμετωπίζοντας (ανησυχία)<br>
      αποφασίσαμε υπέρ του (επιλογή)<br>
      για να επιτύχουμε (ποιότητα)<br>
      αποδεχόμενοι (μειονέκτημα).
* Συζήτηση (Πλαίσιο)
  * Εξηγεί τις δυνάμεις που παίζουν ρόλο (τεχνικές, πολιτικές, κοινωνικές, του έργου).
  * Αυτή είναι η ιστορία που εξηγεί το πρόβλημα που επιδιώκουμε να λύσουμε.
* Λύση
  * Εξηγεί πώς η απόφαση θα λύσει το πρόβλημα.
* Συνέπειες
  * Εξηγεί τα αποτελέσματα της απόφασης μακροπρόθεσμα.
  * Λειτούργησε, δεν λειτούργησε, άλλαξε, αναβαθμίστηκε κ.λπ.
