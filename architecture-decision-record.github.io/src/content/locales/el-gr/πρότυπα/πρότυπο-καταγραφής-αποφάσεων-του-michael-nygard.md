# Πρότυπο καταγραφής αποφάσεων του Michael Nygard

Αυτό είναι το πρότυπο από το [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Μπορείτε να χρησιμοποιήσετε το [adr-tools](https://github.com/npryce/adr-tools) για τη διαχείριση των αρχείων ADR.

Σε κάθε αρχείο ADR, γράψτε αυτές τις ενότητες:

# Τίτλος

## Κατάσταση

Ποια είναι η κατάσταση, π.χ. προτεινόμενη, αποδεκτή, απορριφθείσα, παρωχημένη, αντικατεστημένη κ.λπ.;

## Πλαίσιο

Ποιο είναι το ζήτημα που βλέπουμε και που υποκινεί αυτή την απόφαση ή αλλαγή;

## Απόφαση

Ποια είναι η αλλαγή που προτείνουμε ή/και κάνουμε;

## Συνέπειες

Τι γίνεται ευκολότερο ή δυσκολότερο λόγω αυτής της αλλαγής;
