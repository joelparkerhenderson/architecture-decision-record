# Predložak zapisa odluke – Michael Nygard

Ovo je predložak iz [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Za upravljanje ADR datotekama možete koristiti [adr-tools](https://github.com/npryce/adr-tools).

U svaku ADR datoteku napišite ove odjeljke:

# Naslov

## Status

Koji je status, primjerice predloženo, prihvaćeno, odbijeno, zastarjelo, zamijenjeno itd.?

## Kontekst

Koji je problem koji vidimo i koji motivira ovu odluku ili promjenu?

## Odluka

Koju promjenu predlažemo i/ili provodimo?

## Posljedice

Što postaje lakše ili teže zbog ove promjene?
