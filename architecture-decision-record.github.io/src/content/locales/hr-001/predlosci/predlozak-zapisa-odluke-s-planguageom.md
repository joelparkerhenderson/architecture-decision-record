# Predložak zapisa odluke s Planguageom

Vidi https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Što je Planguage?

Planguage je jezik za planiranje koji koristi ove ključne riječi:

* Tag: Jedinstveni, trajni identifikator
* Gist: Kratak sažetak zahtjeva ili obrađenog područja
* Requirement: Tekst koji detaljno opisuje sam zahtjev
* Rationale: Obrazloženje koje opravdava zahtjev
* Priority: Izjava o prioritetu i pravu na resurse
* Stakeholders: Strane na koje zahtjev materijalno utječe
* Status: Status zahtjeva (nacrt, pregledan, preuzet obveza itd.)
* Owner: Osoba odgovorna za implementaciju zahtjeva
* Author: Osoba koja je napisala zahtjev
* Revision: Broj verzije izjave
* Date: Datum posljednje revizije
* Assumptions: Sve što bi moglo uzrokovati probleme ako sada ili kasnije nije istinito
* Risks: Sve što bi moglo uzrokovati kvar, kašnjenje ili druge negativne učinke
* Defined: Definicija pojma (bolje je koristiti pojmovnik)
