# Zapis arhitekturne odluke: Tailwind CSS

Odluka: Koristiti Tailwind CSS kao CSS okvir za stiliziranje korisničkog sučelja.

## Što je Tailwind CSS?

Tailwind je utility-first CSS okvir koji omogućuje brz razvoj i prilagodbu korisničkih sučelja. Dizajniran je da bude vrlo prilagodljiv i omogućuje programerima pisanje vitkijeg i učinkovitijeg CSS-a. Taj okvir pruža skup unaprijed definiranih klasa za vrlo brzo stiliziranje UI-ja.

## Kontekst

Gradimo web aplikaciju za klijenta koja zahtijeva responzivno i prilagodljivo korisničko sučelje. Klijent je zatražio dosljedno i moderno stiliziranje. Razvojni tim ima iskustva s korištenjem prilagođenog CSS-a, ali želi istražiti CSS okvire koji mogu uštedjeti vrijeme i trud. Tražimo okvir koji je jednostavan za uporabu, prilagodljiv i ima veliku zajednicu za podršku.

## Pokretači odluke

- **Jednostavan za uporabu:**  Želimo okvir koji je jednostavan za učenje i može se integrirati u naš razvojni tijek rada.

- **Prilagodljiv:**  Želimo okvir koji se može prilagoditi smjernicama brenda i temi klijenta.

- **Podrška velike zajednice:**  Želimo okvir koji ima aktivnu zajednicu programera i dizajnera koji mogu pružiti pomoć i resurse kad je potrebno.

- **Ušteda vremena:**  Želimo okvir koji može uštedjeti vrijeme i trud pri stiliziranju UI-ja.

## Razmatrane opcije

- **Bootstrap:**  Popularan CSS okvir s mnogo unaprijed izgrađenih komponenti i velikom zajednicom programera.

- **Foundation:**  Još jedan popularan CSS okvir koji je dizajniran za razvoj s prioritetom mobilnih uređaja.

- **Materialize:**  CSS okvir temeljen na Googleovu jeziku dizajna Material Design s unaprijed izgrađenim komponentama za razvoj UI-ja.

- **Tailwind CSS:**  Utility-first CSS okvir s fokusom na prilagodbu i učinkovitost.

## Ishod odluke

Nakon razmatranja opcija odlučili smo koristiti Tailwind CSS iz sljedećih razloga:

- **Jednostavan za uporabu:**  Tailwindov pristup je jednostavan i lako razumljiv. Njegove utility klase ubrzavaju izradu UI-ja.

- **Prilagodljiv:**  Tailwind omogućuje prilagodbu pružanjem skupa konfiguracijskih datoteka koje programerima omogućuju jednostavnu izmjenu zadanih stilova okvira.

- **Podrška velike zajednice:**  Tailwind ima vrlo aktivnu zajednicu programera i dizajnera koji dosljedno stvaraju nove resurse, dodatke i alate.

- **Ušteda vremena:**  Tailwind može uštedjeti vrijeme, omogućujući programerima da se usredotoče na druga područja projekta.

Koristit ćemo utility klase Tailwind CSS-a za izradu UI-ja našeg projekta. Razvojni tim koristit će njegov atomski i modularni dizajnerski sustav za pisanje učinkovitog i skalabilnog CSS koda. Iskoristit ćemo Tailwindove unaprijed izgrađene predloške i vizualne komponente za ubrzanje razvojnog procesa, a istodobno koristiti prilagođene stilove kako bismo odgovarali brendu i temi klijenta.
