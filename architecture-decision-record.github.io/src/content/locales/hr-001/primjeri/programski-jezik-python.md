## Obrazloženje

Python je svestran programski jezik koji se široko koristi u područjima analize podataka, strojnog učenja i web
razvoja. To je interpretirani jezik, što znači da ga nije potrebno kompajlirati, i ima sintaksu koju je lako čitati i razumjeti. Ostali važni čimbenici naše odluke uključuju sljedeće:

1. **Dostupnost biblioteka:** Python ima golemu zbirku biblioteka i okvira, poput NumPyja, Pandasa i Scikit-learna, što programerima olakšava implementaciju algoritama strojnog učenja i analizu podataka.

2. **Podrška zajednice:** Python ima veliku i aktivnu zajednicu programera koji doprinose njegovu razvoju i pružaju podršku i smjernice na raznim forumima i web-mjestima. To početnicima olakšava pronalaženje pomoći i učenje jezika.

3. **Skalabilnost:** Python je skalabilan, što znači da može obrađivati velike skupove podataka i složene aplikacije. Može se koristiti i za brzo prototipiranje ili izradu malih aplikacija uz minimalan trud, što nam olakšava početak projekta i brzu iteraciju.

4. **Fleksibilnost:** Python se može koristiti za razne vrste projekata, uključujući web razvoj, znanstveno računanje, strojno učenje itd. Također je kompatibilan s drugim programskim jezicima, poput Jave i C++-a, što olakšava integraciju s drugim sustavima.

## Posljedice

Postoje neke moguće posljedice korištenja Pythona kao našeg programskog jezika, kao što su:

1. **Performanse:** Python može biti sporiji od kompajliranih jezika poput C++-a pri izvršavanju određenih algoritama, ali to se može ublažiti korištenjem optimiziranih biblioteka ili pisanjem kritičnog koda u C++-u i povezivanjem s njim iz Pythona.
