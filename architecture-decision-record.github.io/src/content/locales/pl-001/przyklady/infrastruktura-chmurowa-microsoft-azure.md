# Rejestr decyzji architektonicznych: infrastruktura chmurowa Microsoft Azure" 

Tytuł decyzji: Przyjęcie Microsoft Azure jako infrastruktury chmurowej naszej organizacji

Decydent: Dyrektor ds. informatyki (CIO)

Data: 2021-10-15

Status: Zatwierdzony

## Tło

Organizacja planuje migrację z tradycyjnej infrastruktury lokalnej (on-premises) do infrastruktury chmurowej. Aby to osiągnąć, organizacja oceniła wielu dostawców usług chmurowych, takich jak Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure i IBM Cloud. Każdy dostawca ma własny zestaw funkcji, korzyści i strukturę cen. Po szczegółowej analizie stwierdzono, że Microsoft Azure jest najbardziej odpowiednią opcją dla naszej organizacji.

## Decyzja

Przyjąć Microsoft Azure jako infrastrukturę chmurową naszej organizacji.

## Uzasadnienie

Oto powody przyjęcia Microsoft Azure:

1. Kompleksowe usługi: Azure zapewnia pełen zakres usług chmurowych, od infrastruktury jako usługi (IaaS) przez oprogramowanie jako usługę (SaaS) po platformę jako usługę (PaaS). Pozwala to wykorzystać usługi Azure do spełnienia wymagań organizacji, takich jak magazyn danych, moc obliczeniowa, sieci i analityka.

2. Skalowalność i elastyczność: Dzięki Azure możemy łatwo zwiększać lub zmniejszać zasoby zgodnie z potrzebami biznesowymi. Azure oferuje też elastyczność w wyborze systemu operacyjnego, języka programowania i frameworków.

3. Bezpieczeństwo i zgodność: Azure oferuje wysoki poziom bezpieczeństwa i zgodności, ponieważ spełnia kilka standardów branżowych, takich jak ISO, SOC, HIPAA i PCI DSS. Azure zapewnia też zaawansowane funkcje bezpieczeństwa, takie jak grupy zabezpieczeń sieci, zapory i ochrona przed DDoS.

4. Chmura hybrydowa: Azure zapewnia bezproblemowe doświadczenie chmury hybrydowej, umożliwiając organizacjom łączenie infrastruktury lokalnej z Azure. Ułatwia to migrację obciążeń do chmury i daje nam elastyczność wyboru miejsca przechowywania danych.

5. Opłacalność: Azure oferuje model cenowy płatności za rzeczywiste użycie, co oznacza, że płacimy tylko za wykorzystane zasoby. Pomaga to oszczędzać koszty w porównaniu z tradycyjną infrastrukturą lokalną.

## Podsumowanie

Przyjęcie Microsoft Azure jako infrastruktury chmurowej naszej organizacji jest zgodne z naszymi wymaganiami biznesowymi i oferuje kilka korzyści, takich jak skalowalność, elastyczność, bezpieczeństwo i opłacalność. Dlatego zaleca się przyjęcie Azure jako naszej infrastruktury chmurowej.
