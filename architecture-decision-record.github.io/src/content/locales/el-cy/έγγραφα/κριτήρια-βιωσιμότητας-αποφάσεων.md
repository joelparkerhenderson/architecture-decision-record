# Κριτήρια βιωσιμότητας αποφάσεων

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

Για να ορίσουμε αναλυτικά τη βιωσιμότητα των αποφάσεων, εξαγάγαμε πέντε βασικά κριτήρια.

## Στρατηγικό

Κατά τη λήψη αποφάσεων, όποιος εξετάζει τις στρατηγικές συνέπειες πρέπει να λαμβάνει υπόψη πράγματα όπως η μακροπρόθεσμη επίδραση των αποφάσεων — για παράδειγμα, η μελλοντική προσπάθεια λειτουργίας και συντήρησης.

## Μετρήσιμο και διαχειρίσιμο

Μπορείτε να μετράτε και να αξιολογείτε το αποτέλεσμα μιας απόφασης με την πάροδο του χρόνου βάσει αντικειμενικών κριτηρίων, ιδανικά αριθμητικών (όπως, για παράδειγμα, προωθούνται από σενάρια ποιοτικών χαρακτηριστικών και εργαστήρια4). Δεν είναι δυνατή η καταγραφή όλων των λεπτομερών αποφάσεων, επομένως οι αρχιτέκτονες πρέπει να περιορίζουν τη λεπτομέρεια των αποφάσεων σε ένα ορισμένο επίπεδο (όπως η δημιουργία μιας κλάσης σχεδίασης). Αυτό θα οδηγήσει σε ένα πιο βιώσιμο σύνολο αποφάσεων και λιγότερους συνδέσμους ιχνηλασιμότητας. Επιπλέον, ο περιορισμός του αριθμού των εξαρτήσεων μεταξύ αποφάσεων μειώνει το φαινόμενο διάδοσης των αλλαγών.

## Εφικτό και ρεαλιστικό

Η αιτιολόγηση της προσαρμογής της λύσης στο πρόβλημα πρέπει να επιλέγεται πραγματιστικά και να γίνεται ρητή. Για παράδειγμα, οι αρχιτέκτονες μπορούν να υποδείξουν ότι φρόντισαν να αποφύγουν την υπερβολική ή ανεπαρκή μηχανική (δηλαδή πρέπει να εφαρμόζουν την προσέγγιση «αρκετά καλό»).

## Ριζωμένο στις απαιτήσεις

Η λήψη αποφάσεων πρέπει να βασίζεται στην αρχιτεκτονική εμπειρία και το πλαίσιο του συγκεκριμένου τομέα. Πρέπει να λαμβάνει υπόψη το περιβάλλον της εταιρείας καθώς και τις απαιτήσεις και τους περιορισμούς του έργου, συμπεριλαμβανομένων των τρεχουσών δεξιοτήτων της ομάδας ανάπτυξης, του προϋπολογισμού εκπαίδευσης και της διαδικασίας.

## Διαχρονικό

Οι αποφάσεις πρέπει να βασίζονται σε εμπειρία και γνώση που δεν είναι πιθανό να ξεπεραστούν σύντομα. Για παράδειγμα, οι αρχιτέκτονες μπορούν να επιλέγουν αρχιτεκτονικά μοτίβα ή τακτικές ανεξάρτητα από την πλατφόρμα.
