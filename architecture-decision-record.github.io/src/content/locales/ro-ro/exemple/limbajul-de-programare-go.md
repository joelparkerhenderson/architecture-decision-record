# Înregistrare a deciziei de arhitectură: limbajul de programare Go

Titlu: Adoptarea limbajului de programare Go

Stare: Acceptată

## Context

Organizația noastră a folosit în principal limbajul de programare Java pentru construirea de aplicații web. Totuși, ne confruntăm cu unele dificultăți din cauza verbozității Java și a complexității unor framework-uri. De asemenea, echipa noastră a arătat interes pentru explorarea limbajelor de programare moderne, pentru o dezvoltare mai eficientă și mai robustă. După cercetări, am identificat Go ca o soluție potențială la problemele cu care ne confruntăm în Java.

## Decizie

Vom adopta limbajul de programare Go pentru construirea aplicațiilor web de acum înainte.

## Justificare

1. **Simplitate și lizibilitate:** Go este cunoscut pentru simplitatea și sintaxa sa concisă. Aceasta face codul ușor de citit și de scris, reducând complexitatea procesului nostru de dezvoltare.

2. **Performanță ridicată și scalabilitate:** Go este compilat în cod mașină care rulează nativ pe server. Rezultă timpi de execuție mai rapizi și performanță mai bună în comparație cu limbajele interpretate precum Java. În plus, modelul de concurență al Go gestionează mai multe cereri simultan, ceea ce îl face foarte scalabil.

3. **Suport puternic al comunității:** Go are o comunitate vibrantă de dezvoltatori care au contribuit la creșterea sa de-a lungul anilor. Aceasta înseamnă că există multe resurse, biblioteci și framework-uri care ne ajută să începem și să construim aplicații robuste.

4. **Flexibilitate:** Go poate fi folosit atât pentru dezvoltarea front-end, cât și back-end. Aceasta înseamnă că putem valorifica avantajele sale în ambele domenii pentru proiectele noastre de dezvoltare.

## Implicații

1. **Instruire:** Dezvoltatorii noștri vor trebui să urmeze instruire pentru a învăța limbajul de programare Go și nuanțele sale.

2. **Experiență:**  Putem întâmpina unele dificultăți la trecerea de la Java la Go. Dezvoltatorilor noștri le poate lua ceva timp să devină competenți în noul limbaj.

3. **Instrumente:**  Va trebui să adoptăm instrumente și framework-uri noi, specifice Go. Totuși, putem valorifica infrastructura existentă pentru a minimiza impactul acestei schimbări.

4. **Dependența de furnizor:**  Go este un limbaj de programare open source și nu vom fi legați de niciun furnizor sau prestator de servicii.

## Concluzie

Adoptarea limbajului de programare Go ne va ajuta să îmbunătățim procesul de dezvoltare și să construim aplicații robuste. Va trebui să investim resurse în instruire și instrumente pentru a susține această tranziție, dar credem că beneficiile acestei decizii depășesc costurile.
